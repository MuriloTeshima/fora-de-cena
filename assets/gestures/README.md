# Ilustrações dos gestos

Estas imagens são usadas somente na interface e no README:

| Arquivo | Gesto |
|---|---|
| `teleporte.png` | Indicador e médio juntos na testa |
| `selo-uma-mao.png` | Selo ninja com uma mão |
| `poeira.png` | Preparação e movimento visual do estalo |
| `digital.png` | Pinça se abrindo |
| `palma.png` | Palma aberta e parada |
| `portal.png` | Duas palmas nas laterais do rosto |
| `manual.png` | Ativação manual |

Os PNGs preservam transparência e proporção. As instruções e o vínculo com os
efeitos estão em `teleport_cam/gesture_guides.py`. As ilustrações antigas e os
prompts usados em sua criação não são necessários para executar ou construir o app.
